```powershell
mvn -B -pl campus-common test
```

结果：`Tests run: 20, Failures: 0, Errors: 0, Skipped: 0`。

覆盖内容：

- 缺少数据库、缓存、MyBatis 加密密钥、微信和支付回调配置时，以稳定错误码 `CONFIGURATION_INVALID` 拒绝生产启动。

```powershell
  '-Dcampus.valkey.host=127.0.0.1', '-Dcampus.valkey.port=6379',
  '-Dcampus.valkey.password=<local-only-password>', 'test'
)
mvn @mvnArgs
```

## 6. 架构复核修正

执行代理完成实现后，架构复核发现并修正三项问题：

1. readiness 曾向任意登录用户暴露依赖明细，现统一只返回 `UP/DOWN`；内部诊断留给 M11.06 的专用运维权限。
2. readiness 曾把依赖 `UNKNOWN` 当作可用，现只有全部依赖明确 `UP` 才就绪。
3. 生产守卫最初只校验数据库、缓存和网关，真实启动暴露出 WxJava 与支付属性的隐含必填项；现全部前置校验并提供明确变量名。
