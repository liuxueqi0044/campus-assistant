# M01.02 前端真实 context / 学校目录适配报告

## 范围

- 仅修改 `apps/student/src/services/api.ts`、`apps/student/src/types.ts`、前端联调测试和本目录联调说明。
- 保留 demo 分支、既有页面视觉和迟到响应保护；未修改 `backend/`、`contracts/` 或 `database/`。

## 已完成

1. 真实刷新读取 `GET /context` 与 `GET /schools`，以学校目录作为公开 `campuses` 来源，再合并当前 context 的选择与用户状态。
2. 同时兼容 canonical `schoolId`/`campusId` 与 legacy `id`，每个前端校区模型保留 `schoolId`。
3. `ENABLED`/`ACTIVE` 映射 `enabled: true`，`DISABLED`/`INACTIVE` 映射 `enabled: false`。
4. 识别 context 顶层 `loggedIn`；没有权威 `user` 字段时不生成 `userId`、认证状态或跑腿权限。
5. 没有当前校区选择时，使用第一个启用目录校区作为公开浏览默认值，不发送 PUT；没有启用校区时保持空选择并显示“暂无可用校区”错误状态。
6. `switchCampus` 继续调用 `PUT /context`，发送所选校区的权威 `schoolId` 与 `campusId`。
