# M10.01 视觉与基础组件复用审查

日期：2026-09-18。范围：`frontend/apps/student/src` 的主题、通用组件与页面布局；本次只做静态复用审查，
不改变组件行为、不接业务接口。

## 已确认的复用基础

- `styles/theme.scss` 集中定义主色 `#07855d`、白灰背景、正文/次要文字、边线、按钮、卡片、字号倍率和安全区
  规则；`.page` 统一使用全宽布局并限制手机/桌面内容最大宽度 520px。
- `PageHeader` 统一处理标题、副标题、返回按钮、右侧插槽、状态栏间距和 350px 窄屏字号；页面详情、表单、
  登录和课表等入口均复用它。
- `BottomNav` 统一提供校园、课表、消息、我四个入口，使用 `aria-current`/`aria-label`，展示服务端消息与通知
  未读数，并保留底部安全区；首页、课表、消息和个人中心复用它。
- `EmptyState` 统一提供图标、标题、说明和插槽，商品、跑腿、活动、课表、消息、详情和个人记录页面复用它。
- 页面普遍支持 `large-type` 字号倍率；主题在 350px 以下收窄左右间距，课表周视图明确保留内部横向滚动，避免
  把整页宽度扩出视口。

## 可验证缺口

`frontend/docs/本次验收结果.md` 引用了 `artifacts/responsive-report.json`、浏览器流程和截图，但这些 artifacts 不在
当前 Git 树中（仅能确认文档中的历史描述，不能复核对应版本、视口和截图）。因此本次不能将 M10.01 的独立视觉验收
标为 PASS；需要后续在固定提交上重新生成并保存 320/390/430px、较大字号、安全区和无横向溢出的报告，再由负责人复核。
