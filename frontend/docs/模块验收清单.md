# 校园助手学生端：模块验收清单

日期：2026-09-17。适用目录：`apps/student`。本文记录前端交付范围和待执行回归方法，不是浏览器、微信真机或真实后端验收通过报告。实际结果须附运行版本、截图或日志；页面存在与编译通过不等于业务后端已经成立。

## 1. 验收层级与环境

| 层级 | 范围 | 不能替代的验证 |
|---|---|---|
| 静态／构建 | TypeScript、H5 构建、小程序编译、单元测试 | 不证明界面无溢出、微信权限可用或资金正确 |
| A：前端 demo | 固定虚构种子、内存异步 API、手机尺寸交互回归 | 不证明并发接单、名额锁、鉴权、真实通知或到账 |
| B：后端集成 | real 模式、真实 API 与数据库、可控渠道适配器 | 不证明微信真机与实际商户权限 |
| C：真机／渠道 | 微信登录、授权上传、订阅通知及获批小额资金 | 需相应真实外部条件，不可用 demo 画面充当证据 |

环境变量以仓库配置说明为准：`VITE_API_MODE=demo` 使用演示适配器；`real` 使用后端传输层且不得降级为模拟成功。demo 种子在 `src/data/demo.ts`，为虚构的榆川大学东／西校区；内存演示状态可在设置中重置，刷新或重启后的状态不应被当作服务端持久化记录。

可执行脚本定义在 `apps/student/package.json`：`npm run typecheck`、`npm run build:h5`、`npm run build:mp-weixin`、`npm test`。本清单不替实际执行者标记这些脚本已通过，也不要求每一轮重复全部构建。所有通过结论应记录对应提交和变更范围。

## 9. 后端接入必须补验

1. 身份：code 换登录态、令牌失效、退出失效、多用户与跨校区权限；后端不能相信前端 memberId 或金额。
2. 数据：详情/列表/私人记录分别完整返回；刷新、冷启动与深链接不能依赖先打开首页才有记录；接口失败不回落 demo。
3. 交易：服务端报价快照、幂等键、并发接单、容量与预约唯一性；客户端 busy 只改善体验。
4. 资金：官方收款、回调验签/查单、退款、结算、跑腿员转付与对账。客户端成功页面不更新可信到账状态。
5. 内容：上传授权、归属、私有文件访问、发布审核、举报/争议证据和受限后台访问。
6. 课表：真实导入解析与字段校验、异步任务恢复、低置信核对、版本冲突与撤销。
7. 消息：持久化发送确认、实时连接、断线补拉、旧消息变更、多端已读与订阅权限。
8. 真机：微信登录、日期时间 picker、文件选择、软键盘、安全区、分享冷启动、前后台切换及弱网。
