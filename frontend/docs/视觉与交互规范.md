# 校园助手视觉与交互规范

定位为学生每天能轻松打开的校园工具。沿用原型的信息结构，实际页面使用 uni-app 标签与独立组件实现。

## 基础视觉

| 项目 | 约定 |
|---|---|
| 主色 | #07855D，用于当前导航、主按钮、成功/可执行状态 |
| 背景 / 卡片 | #F7F8F7 / #FFFFFF |
| 正文 / 次要文字 | #202B25 / #78837C |
| 边线 | #E9EEEA，1px |
| 价格 | 暖棕色 #B15C3D，避免大面积强红 |
| 字体 | 系统中文无衬线；正文15–16px，标题18–23px，辅助12–14px |
| 间距 | 页面两侧20px，320px屏为16px；卡片内12–20px |
| 圆角 | 主要8–12px；不过度胶囊化 |
| 操作 | 主按钮至少44–48px高，底部考虑安全区 |
| 宽度 | 手机全宽；桌面居中最大520px |

底部导航依次校园、课表、消息、我。校园内部二手/跑腿/活动为二级标签，发布入口跟随当前业务。筛选用轻量横向分类，详情保持独立返回路径。

## 各模块

- 二手：两列商品卡，物品图片优先；价格、成色、同学与公共交接地点紧邻物品。
- 跑腿：一列任务卡，起终点与报酬清楚可扫读；详情时间线区分接单、取件、送达和收件确认。
- 活动：横向海报、一列信息卡；正式名额与候补状态明确分开。
- 课表：优先今日列表，可切一周表格；柔和课程色块，时间冲突有额外入口。
- 消息：类似熟悉的聊天列表与气泡，商品/订单上下文在对话顶部。
- 我的：身份卡、业务记录、分组设置，减少多层菜单。

## 反馈

操作中按钮防重复；成功显示具体状态；失败保留输入并显示可读错误；空态说明如何继续。危险或会丢弃内容的操作给确认/取消路径。演示身份、数据、支付、签到和课表导入有明确提示。

本地插画用于演示，不能代替真实商品照片。SVG源文件可编辑，运行时PNG避免小程序本地SVG兼容问题。字体不依赖外部CDN；Wot小程序图标字体当前使用该库默认网络字体，真机验收需检查加载。
